# ProAudio — Áudio e Iluminação Profissional

Landing page institucional desenvolvida para a **ProAudio**, empresa especializada em soluções completas de sonorização, iluminação cênica e estruturas para eventos corporativos, shows, festas e celebrações.

O objetivo principal do site é servir como vitrine comercial, apresentando a infraestrutura técnica da empresa, o portfólio de eventos atendidos e facilitando a captação de leads com canais diretos para orçamento.

---

##  Estrutura e Seções do Site

* **Hero Section:** Apresentação visual de impacto com proposta de valor clara e chamada para ação (CTA) focada em solicitação de orçamento.
* **Serviços:** Detalhamento das soluções oferecidas, cobrindo sonorização de ambientes, iluminação de palco/cênica, painéis de LED e montagem de estruturas.
* **Equipamentos & Infraestrutura:** Destaque para o padrão técnico do acervo (sistemas de som PA, mesa de som, refletores, fumaça e treliças).
* **Portfólio / Galeria:** Exibição visual de eventos já realizados, destacando a presença de palco e a ambientação criada pela iluminação.
* **Depoimentos & Diferenciais:** Seção dedicada a passar credibilidade técnica, pontualidade de montagem e suporte ao vivo durante os eventos.
* **Contato Comercial:** Formulário direto e botões de atalho com integração rápida para o WhatsApp comercial e redes sociais.

---

##  Destaques de Desenvolvimento

* **Interface Focada em Conversão:** Layout limpo, responsivo e adaptado para navegação rápida tanto em dispositivos móveis quanto em desktop.
* **Design Modular:** Componentização em React 19 para fácil manutenção e atualização das seções de serviços ou galeria.
* **Visual Leve e Moderno:** Estilização utilitária com Tailwind CSS v4 e iconografia precisa com Lucide React para sinalizar visualmente cada categoria de equipamento.
* **Código Limpo:** Padrão de código verificado via Oxlint para manter alta performance e carregamento instantâneo.
